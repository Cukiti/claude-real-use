# Real Use para Gemini

No se instala solo. Apunta Gemini a este plugin y sigue `instrucciones/retomar.md`.

El resumen es el de `scripts/retomar.js`:

`node scripts/retomar.js "<raíz del proyecto>"`

Muestra esa salida tal cual. No pidas al usuario que cuente en qué se quedó. Si contiene `Desfase:`, pregunta antes de editar.
